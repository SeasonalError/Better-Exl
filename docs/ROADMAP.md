# Roadmap

Future features should preserve measurements, state assumptions and pass numerical reference tests before appearing in the interface.

1. Shared calibration sources across rows, generalized least squares, correlated X/Y errors, Monte Carlo propagation and theory uncertainty bands.
2. Poisson count likelihoods, robust regression, bootstrap intervals, multi-peak models and derived quantities using full fit covariance.
3. Serial/USB acquisition, live traces, calibration records and recoverable measurement logs, with instrument-specific protocols.
4. Calibrated video tracking, image profiles and spectral extraction with calibration uncertainty.
5. Large-dataset storage, background computation/cancellation, revision compaction with backups, packaged desktop launchers and cross-platform browser CI.
6. Guided uncertainty exercises, accessible graph editors and institution-authored templates that separate synthetic and experimental data.
7. Frozen environment manifests, notebook export and optional isolated Python execution.

Public collaboration is a separate deployment project requiring authentication, authorization, quotas and a suitable server. V1 is a single-user loopback application.
